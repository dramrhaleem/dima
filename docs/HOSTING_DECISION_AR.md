# ديمة — قرار الدومين والاستضافة المعتمد

> أولوية التنفيذ الحالية: [مسار الإطلاق المختصر](WEB_RELEASE_FAST_TRACK_AR.md). التفصيلات الموسعة أدناه مرجع تصميم؛ لا تجعل اختبارات التحمل أو سجل D1 المستقل أو تصدير الأحجام الضخمة شرط إطلاق. التنفيذ الفعلي وحدوده في STATUS_AR.md.
التاريخ: 31 أكتوبر 2026. إصدار الحزمة: 1.1. الحالة: قرار وافق عليه المستخدم وطلب تسجيله؛ ليس نشرًا أو تفعيلًا للخدمات.

## القرار

| الجزء | الاختيار المعتمد |
|---|---|
| الدومين | `dima.study`؛ أكد المستخدم حجزه لدى Spaceship |
| DNS | Cloudflare؛ تسجيل الدومين يظل لدى Spaceship |
| الواجهة والـAPI والملفات الثابتة | Cloudflare Workers؛ لا حاجة إلى مشروع Pages منفصل في البداية |
| البيانات والحسابات والتحديثات اللحظية | Supabase Free: PostgreSQL + Auth + Realtime |
| تسوية البيانات والوظائف المجدولة | Supabase Cron + وظائف DB قصيرة/dispatcher محمي على Workers، وفق عقد المعمارية |
| الجمهور المتوقع | 50–100 مستخدم وفق تقدير المستخدم؛ عدد المتزامنين لم يُحسم بهذا التقدير |
| التكلفة الابتدائية | البدء بالخطط المجانية وقياس الاستهلاك؛ أي ترقية مدفوعة تحتاج موافقة مستقلة |

لا ننقل قاعدة بيانات المنصة إلى D1 أو الغرف إلى Durable Objects في هذا الإصدار. استثناء تقني معتمد في 1 نوفمبر 2026: D1 مستقلة على Free لسجل الخصوصية المشفّر التقييدي فقط، وفق [ملحق السجل والاستعادة](PRIVACY_LEDGER_CONTRACT_AR.md)؛ local adapter للتطوير، بلا sockets إضافية. هذا اختيار للتنفيذ وليس إنشاء خدمة أو شراء أو نشرًا. نحتفظ بخدمات Supabase وعقود الصلاحيات والوقت والتقدم الحالية. هذا القرار يحل محل ترشيح Heroku Student السابق؛ لا نحتاج Heroku ضمن هذا التوزيع.

## استضافة Spaceship الحالية

أكد المستخدم امتلاك Web Hosting Essential Trial لمدة شهر. لا نعتمد عليها لاستضافة ديمة ولا نوصي بتجديدها لهذا الغرض. لم تُلغَ التجربة أو يُغيّر التجديد التلقائي، ولم تُفحص إعدادات حسابه. قرار عدم استخدامها منفصل عن الاحتفاظ بالدومين وتجديده.

## حدود القرار وما بقي قبل الإطلاق

- اختيار مسار نشر Next.js المتوافق مع Workers وتثبيت إصداراته واختباره؛ لا نفترض تطابق بيئة Workers مع خادم Node تقليدي.
- اختبار CPU لكل طلب وحساب الخطة وحفظ التقدم، لا الاكتفاء بعدد المستخدمين. الحد المجاني الحالي للـWorkers هو 100 ألف طلب/يوم و10ms CPU للطلب؛ هذه ليست مدة انتظار الشبكة.
- تبقى حدود Supabase واختبارات الغرف والأمان والاستعادة والخصوصية في الوثائق المختصة كما هي. لا تخفيض وظائف أو اختبارات الجودة لتلبية وصف «مجاني».
- ربط DNS والشهادة والبريد وتفعيل المشاريع خطوات تنفيذ لاحقة. ملكية الدومين مستندة إلى إفادة المستخدم، ولم تُتحقق من حساب المسجل.
