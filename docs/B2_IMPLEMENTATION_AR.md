# B2 — خطة التنفيذ والحالة

31 أكتوبر 2026. نُفذ محليًا بعد تحسين الدارك؛ [سجل الأدلة والحدود](evidence/B2.md). لا نشر عام أو خدمات مدفوعة ضمن هذا العمل.

1. تحسين طبقة الثيم مع حفظ أصول الهوية الأصلية؛ مراجعة Settings وToday على الهاتف والكمبيوتر قبل بدء تنفيذ B2.
2. تثبيت فهرس الكورسين بمصادر رسمية وحدود واضحة للترتيب والتقديرات؛ النسخة التي ينضم إليها المستخدم ثابتة.
3. عقود ومخطط وصلاحيات: كورس خاص قابل للتحرير كمسودة، نطاق وسابق مستقل، تقدم وأحداث قابلة للإعادة، معاينة وتطبيق ذري مع رفض التغير الخارجي.
4. محرك حتمي بسعة أسبوعية واحدة لكل الكورسات، احتياطي 15%، ترتيب ومتطلبات، هدف مقابل توقع وأعمال غير موزعة بلا ادعاء Fits عند نقص التقديرات.
5. واجهات Library / My Courses / Course / Setup / Preview / Plan / Today؛ المصدر والإكمال والتراجع، وإبقاء المدخلات عند فشل الحفظ.
6. تحقق من رحلة فعلية وحفظ وإعادة تحميل وجهاز ثانٍ؛ عزل الحسابات والسعة المشتركة والسابق والإعادة والتعارض. بناء Workers، فحص بصري، ومراجعة مستقلة قبل التسليم.

الاستدراك المتقدم والجزئي B3، المؤقت B4، الغرف B5، المشاركة والترتيب B6. تعرض الواجهة حدود الأجزاء المستقبلية بصدق.

## ما نُفذ

طبقة الدارك مستقلة عن الأصول الأصلية، مع فصل لون الزر عن لون الرابط واستخدام الشعار المعكوس. الكتالوج يضم 711 نشاطًا من مصدرين، والنطاق الأساسي يستبعد الإضافات والبدائل؛ تفاصيل التدقيق مستقلة.

الحالة الخاصة محفوظة كتجميعة JSONB ذات revision، مع إيصالات أوامر مختصرة وقراءة RLS للمالك وكاتب خادم فقط. هذا اختيار تنفيذ B2 لتطبيق الخطة والتقدم ذريًا؛ لا يمثل نشرًا اجتماعيًا أو قياسًا لقدرة الاستضافة. واجهات المستخدم ومحرك الخطة مشتركة المصدر وقابلة للاستخدام خارج Next؛ غلاف Android نفسه لم يُنشأ.

تعرض الواجهات خطة محفوظة واضحة وتطلب إعادة المعاينة عند تغير مدخلاتها؛ لا تعيد توزيع أيام المستخدم تلقائيًا. الخطوات المتقدمة للاستدراك تبقى B3. [عقد التنفيذ](B2_API_AND_LEARNING_AR.md) و[الشاشات](surfaces/b2-learning.md).

اختيار السابق يدعم كل نشاط أو الأنشطة المختارة داخل موديل كامل بإجراء صريح، دون إدخال الأنشطة الاختيارية إلى النطاق. الجدول يعرض أول سبعة أيام دراسة مع العدد الإجمالي وزر لعرض الباقي؛ الأعمال غير الموزعة وإقرار الخطة الجزئية يظلان ظاهرين.
