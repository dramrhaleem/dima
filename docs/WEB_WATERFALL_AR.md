# تنفيذ الويب حتى نهاية المراحل

> تحديث ملزم: [مسار الإطلاق المختصر](WEB_RELEASE_FAST_TRACK_AR.md) يطبق طلب المستخدم الأحدث بتقليل التدقيق المطول وأولوية الواجهة والوظائف والنشر. بوابة7200+600 السابقة لم تعد شرط انتقال؛ لا تُحوّل نتيجتها غير المكتملة إلى نجاح.

قرار المستخدم، 31 أكتوبر 2026: الويب فقط؛ لا APK أو غلاف هاتف أو M0/M1/M2 حاليًا. تنفيذ مرحلة كاملة ثم مراجعتها وإصلاحها والتحقق من اتساقها قبل التالية. الوثائق الأصلية عقود وظيفية؛ [الحالة](STATUS_AR.md) تسجل التنفيذ الفعلي.

## التسلسل وبوابات الانتقال

| المرحلة | النتيجة المطلوبة | بوابة الإغلاق |
|---|---|---|
| B3 | عمل جزئي، متبقٍ، استدراك ومعاينة وتوقفات ومثبتات | RC01–RC13 + رجوع الحسابات والتنقل + مراجعة UI والأداء |
| B4 | سجل وقت واحد، Pomodoro/Open/Work، pause/resume/finish/review وتصحيح وانقطاع | TM01–TM07 وOP01 وAC02–AC04؛ لا وقت مزدوج أو استراحة محسوبة |
| B5 | غرف موضوع/كورس، جولات مشتركة وحضور وتحكم ونقل وإشراف | RF01–RF22، خصوصية وتزامن وحمل محلي موثق |
| B6 | تقدم ونشاط ومتابعة اختيارية وترتيب ومساهمات وإدارة وإشعارات وتصدير/حذف | AC05 وSC/LB/CM/OP03، عزل فعلي وإلغاء مشاركة فوري |
| B7 | تشغيل واستعادة وأداء ووصول وحماية وتجهيز إطلاق الويب | مصفوفة D01–D15 مع حدود الأدلة، دون خلط اختبار محلي بإنتاج |

لا يبدأ كود المرحلة التالية قبل تقرير تحقق ومراجعة للحالية ومعالجة العيوب المانعة. يسمح بعمال متوازية داخل المرحلة، بملكية ملفات واضحة ودمج متسلسل. لكل مرحلة: عقود وحدود → مجال وتخزين ومعاملات → API → واجهات حقيقية → اختبارات وظيفية وأمنية وتجربة استخدام → مراجعة مستقلة → إصلاح وتحقق متناسب → توثيق.

## قواعد ثابتة

- واجهة إنجليزية فاتحة فقط، مع حفظ الهوية واللاندنج؛ responsive للمتصفح على الهاتف لا يعني بناء تطبيق هاتف.
- الخادم هو المرجع للهوية والوقت والمعاملات، والمجال مستقل عن Next/DOM. لا تنسخ schema وأسرار الخادم إلى حزم المتصفح بسبب استيراد ثابت مشترك.
- وقت المؤقت والجهد التقديري والإكمال والسابق قيم مختلفة. إعادة الطلب وفقد الرد والتبويبان لا تضاعف الوقت أو الإنجاز.
- فشل الشبكة يحفظ المدخلات؛ تحديث الخلفية لا يبدل الصفحة البيضاء ولا يمسح المسودة؛ تغير الحساب يمسح العرض الخاص.
- اختبار أداء ببيانات واقعية متراكمة، وحزم المتصفح والتجاوب والكيبورد وreduced motion؛ لا ادعاءات سرعة بلا قياس.
- لا شراء أو ترقية مدفوعة تلقائية. التحقق المحلي، البيئة البعيدة، إطلاق التسجيل العام وتجربة بشرية فعلية حالات مستقلة في الأدلة. لا يُختلق اختبار خمسة أشخاص أو نشر غير منفذ.

## التجربة الشاملة بعد المراحل

1. **رصد فقط:** تجربة الرحلات من البداية للنهاية، حالات المستخدم الجديد والعائد وWork-only، الفشل والانقطاع والتعارض والخصوصية، أحجام العرض والوصول والأداء والوضوح. جمع كل النتائج قبل بدء إصلاحات هذه الجولة.
2. **تقرير واحد:** `docs/evidence/WEB_FULL_AUDIT_AR.md`؛ لكل ملاحظة شدة وتأثير وخطوات إعادة وإثبات وسبب وحل مقترح. تمييز العطل عن تحسين اختياري، وعدم اختلاق مشاكل لزيادة القائمة.
3. **الإصلاح:** بدء الإصلاح بعد اكتمال الرصد والتقرير، بالأولوية؛ تحديث الحالة والدليل لكل ملاحظة.
4. **مراجعة سريعة أخيرة:** تحقق الحلول والرحلات الأساسية وعدم الرجوع، وتسجيل أي حدود فعلية باقية. لا يعتبر الكود أو البناء وحده إثبات إطلاق أو قبول مستخدمين.
