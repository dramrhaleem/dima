# B3 — خطة تنفيذ الاستدراك والعمل الجزئي

الحالة: اكتمل التحقق المحلي؛ [الأدلة](evidence/B3.md)، 31 أكتوبر 2026. المطلوب تنفيذ محلي قابل للاستخدام والاختبار، دون نشر أو مؤقت أو غرف أو منافسة.

## قرار التسلسل والحدود

طلب المستخدم بدء B3 مباشرة. M0 لم يُنفذ؛ نتقدم وفق طلبه مع مراجعة الحدود المعمارية الحالية (مجال TypeScript مستقل، API مشتركة، UI بلا اعتماد على Next في منطق التعلم). هذا لا يحقق AND01–AND03/AND08 ولا يثبت تشغيل Android؛ ثم أجّل المستخدم الهاتف صراحة؛ لم يعد M0 اعتمادًا للويب في [التسلسل الحالي](WEB_WATERFALL_AR.md). الوضع الفاتح فقط وتحسينات التنقل وتحديث الجلسة في الخلفية من المتطلبات الحالية.

## التنفيذ بالترتيب

1. تثبيت امتداد عقد التعلم، مع قراءة بيانات B2 القائمة دون إعادة ضبط، وتحديد مصدر كل جهد ومعنى المتبقي والهوية الثابتة للأحداث.
2. محرك جزئي واستدراك حتمي: عمل مستقل/عمل ناتج من إكمال، متبقٍ مؤكد أو مجهول، تقدير الجهد المجهول وتصحيحه، أولويات وتوقف مؤقت واستثناءات وراحة ومثبتات. السعة واحدة والاحتياطي لا يُستخدم إلا باختيار صريح.
3. معاينة قبل/بعد تُبقي الهدف الأصلي وتعرض forecast وأسباب التغيير والعجز. تعارض المثبتات يمنع التطبيق؛ الجزء الممكن يحتاج إقرارًا. Undo للاستدراك يُنتج معاينة جديدة من إعدادات سابقة وتقدم حالي.
4. واجهات Today وTask وRecovery وMy Plan/Courses: Start small حقيقي، Worked on منفصل عن Complete، حفظ فاشل يحتفظ بالمدخلات، وفهرس المتبقي لا يختفي.
5. تكامل وتحقق RC01–RC13، مع حالات DST/منتصف الليل، جهازين وتعارض revision، فقد الرد وإعادة الطلب، وتوافق بيانات B2. مراجعة مستقلة ثم بناء Workers واختبار الواجهات على أحجام الهاتف والكمبيوتر.

## تقسيم المسؤوليات

- عقود/مجال/API واختبارات المجال والتكامل: عامل الباك إند؛ يثبت الواجهات أولًا وينسقها مع عامل UI.
- شاشات/أنماط B3 واختبارات المتصفح: عامل UI؛ يحافظ على White-only وNavigationProvider وكاش الحساب المعزول.
- مراجعة مستقلة: عامل المراجعة، مع RC matrix وتقييم معماري محدود، دون تعديل ملفات التنفيذ.
- الدمج والبناء والتحقق النهائي وتوثيق الحالة: العامل الرئيسي.

## معايير النجاح

- 120 أصلًا، Worked40، remaining80، Complete80: استهلاك120 فقط. Undo mistake يبطل80 المشتقة دون الأربعين المستقلة؛ Reopen يحتفظ بالعمل الحقيقي ويطلب المتبقي.
- Remaining100 وPinned45 يتركان55 مرنة. Ceiling180 − reserve27 − accepted40 − pin45 يترك68؛ لا قص صامت ولا خصم تايمر.
- Unknown لا يصبح صفرًا أو أصلًا جديدًا، ولا ينتج Fits زائفة. كل المتبقي موزع أو ظاهر كغير موزع/متوقف.
- فوات أيام لا يصفر التقدم؛ راحة/Pause ليسا تعثرًا. قبول معاينة لا يغير التاريخ، وUndo recovery لا يستعيد تقدمًا قديمًا.
- أي تغير مؤثر أو منتصف ليل/Timezone أو انقضاء24ساعة يبطل المعاينة؛ لا يتجاوز العميل هذا الفحص.
- تظل اختبارات الحسابات والتنقل وعدم فقد المسودة ناجحة. النتيجة المحلية منفصلة عن الإنتاج وAndroid.
