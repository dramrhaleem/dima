# B4 — سجل الوقت والتركيز الفردي

الحالة: مكتمل ومتحقق محليًا؛ [الأدلة](evidence/B4.md). الويب فقط وفق [Waterfall](WEB_WATERFALL_AR.md). أُغلقت ملاحظات B4 المانعة قبل الانتقال إلى B5.

## النتيجة

جلسة واحدة للحساب عبر صفحات الويب وتبويباته وأجهزته، تدعم Work وLearning وOpen وPomodoro. وقت التركيز محفوظ من الخادم؛ الاستراحة والإكمال وجهد التخطيط مفاهيم مستقلة. المستخدم يرى المزامنة والتحكم والتصحيح بدل نجاح بصري غير محفوظ.

## التنفيذ والملكية

1. عقد الوقت وحالاته وعلاقة Session/Interval/Correction والتحكم والإيصالات، ومراجعة مستقلة قبل التوسع.
2. تخزين وصلاحيات ومعاملات ذرية: حد جلسة واحدة وفترة واحدة مفتوحة وعدم تداخل الرصيد، تسوية نهاية مخزنة، وتصحيح الفترة المقصودة فقط. سجلات jobs/outbox قابلة لإعادة المحاولة بلا مضاعفة.
3. API للقراءة والأوامر: هوية الحساب من الجلسة؛ Start/Pause/Resume/Finish/Takeover/Review/Manual/Correction. لا استيراد صلاحيات أو ساعة من العميل.
4. Focus وسجل Activity وملخص وشريط جلسة مستمر، مع ساعة عرض مربوطة بوقت الخادم، حفظ محلي مثبت لقصد الإيقاف دون شبكة، وتحديث خلفي يحفظ المدخلات.
5. تحقق TM01–TM07 وOP01 وWork-only وعزل الحسابات، API فعلية وسباقات وتكرار، متصفح ومراجعة صور وأداء وحزم. الدمج والبناء متسلسلان بعد تجميد المصدر.

الباك إند يملك العقود والمجال والـSQL وواجهات الخادم واختباراتها. الواجهة تملك Focus/Activity/outbox وتكامل shell واختبارات المتصفح. المراجع مستقل ويكتب [تقرير المراجعة](evidence/B4_REVIEW.md). العامل الرئيسي يدمج ويطبق migrations إضافية بأمان ويشغل البناء ويتحقق ويوثق.

## قواعد القبول الحاسمة

- Start متزامن ينتج جلسة واحدة. عملية مكررة تعيد نتيجة محفوظة؛ تغيير payload لنفس الهوية مرفوض.
- نهاية Pomodoro محفوظة ومحدودة: Finalized عندها ولو تأخرت التسوية، ولا وقت للاستراحة أو الجولة التالية. Open يبلغ سقف الفترة4ساعات ويحتاج مراجعة.
- Pause يغلق فترة؛ Resume يبدأ فترة جديدة من المتبقي. Takeover يرفض أوامر التحكم القديمة ويحمي عمل الجهاز الجديد من قصد إيقاف قديم.
- Offline Stop يعيد طلب/فحص العملية الأصلية أولًا؛ إذا كان الخادم حفظها فلا تصحيح جديد. إن لم تصل، تصحيح شخصي للفترة المقصودة؛ لا يُسقط أهلية الفترات السابقة السليمة.
- اليدوي ظاهر كمصدر شخصي خارج المنافسة؛ التداخل لا يُحسب مرتين. لا تُنشأ ساعات من Worked on أو Complete.
- الطابور المحلي مرتبط بالحساب والجهاز؛ لا يراه حساب آخر ولا يُرسل بأذون حساب آخر. لا ادعاء Saved قبل commit أو Pending sync قبل حفظ محلي فعلي.
- لا تعتمد صحة السقف على interval في المتصفح أو Cron في موعده. dispatcher محمي ومحدود، والإيصال والـoutbox في المعاملة نفسها.
