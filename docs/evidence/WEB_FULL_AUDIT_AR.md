## حدود الإطلاق المتبقية

النشر لم يتم؛ Wrangler غير مسجل دخول والمتصفح المتاح يعرض صفحة دخولCloudflare. لا إثبات استضافةSupabase أوSMTP أوGoogle العام أوDNS/HTTPS النهائي. وظائف التشجيع والمعالم المنشورة وتعديل هدف الإيقاع وvanity handles وترقية المنهج الاختيارية ليست مبنية بعد؛ لا تعرض كميزات عاملة. الأساس المبني يحفظ نسخة التسجيل الحالية دون تغيير صامت.
