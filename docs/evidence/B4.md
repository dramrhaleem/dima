# B4 — الوقت والتركيز الفردي

الحالة: B4 مكتمل ومتحقق محليًا. أُصلحت الملاحظات المانعة وأُعيد اختبار الحالات المتأثرة ومراجعة الصور. لا نشر مستضاف أو تطبيق هاتف.

## ما بُني

Focus لـWork وLearning، بنمط Open أو Pomodoro وإعدادات التركيز والاستراحة، مع Start/Pause/Resume/Finish والتحكم بين التبويبات والأجهزة. شريط الجلسة يستمر عبر الصفحات، وتنبيه انتهاء الجلسة يربط بملخصها دون تغيير الصفحة أو مسودتها.

سجل مركزي للجلسات والفترات والتصحيحات، بمعاملات تقفل الحساب أولًا وقيود تمنع الجلسات النشطة المتعددة والتداخل. الوقت اليدوي والتصحيح الشخصي منفصلان عن الوقت المؤهل، ولا يُنشئ التايمر إكمالًا لدروس أو جهدًا تقديريًا. Activity بصفحات وتفصيل لكل جلسة.

نوايا الإيقاف تُحفظ محليًا حسب الحساب والجهاز وتُراجع أمام الإيصال الأصلي. انقطاع الشبكة أو فقد الرد أو انتقال التحكم لا يضاعف الوقت ولا يصحح فترة أحدث بالخطأ. فشل التخزين المحلي لا يُعرض كحفظ دائم. المهام المؤجلة لها leases وإعادة محاولة وحالة فشل صريحة؛ النهاية المحفوظة لا تتمدد بسبب تأخر التنفيذ.

العقد والتشغيل في [B4 API](../B4_API_AND_TIME_AR.md) و[التشغيل المحلي](../RUN_LOCAL_AR.md)، والمراجعة المستقلة في [B4_REVIEW](B4_REVIEW.md).

## دليل التحقق الحالي

| الفحص | النتيجة |
|---|---|
| الأنواع وESLint | نجح الفحص العام، ثم الفحوص الموجهة للتعديلات اللاحقة |
| Unit | 82 اختبارًا في المجموعة، ثم 3 اختبارات إضافية لملكية عمليات التشغيل والإيقاف |
| B4 API | 24/24 على قاعدة محلية وWorkers محلي فعلي؛ [النتائج](B4_TIME_API_RESULTS.json) |
| رجوع B2/B3 API | 18/18 و15/15 بعد إضافة سجل الوقت |
| المتصفح — الجولة الأولى | 20/25؛ اختبارات المراحل السابقة الـ17 نجحت. أربع مشاكل في إعداد/انتظار الاختبار، وسباق فعلي عند بدء نشاط لم ينته تحميله |
| المتصفح — بعد الإصلاح | 25 رحلة مختلفة مقبولة: 17 رجوعًا محفوظة و8 حالات B4 بأحدث تشغيل صالح؛ [فهرس الأدلة](B4_BROWSER_ACCEPTANCE.json). ليس ادعاء تشغيل واحد جديد 25/25 |
| الصور والتجاوب | 8 صور عند 320/375/768/1280؛ مراجعة مستقلة ومراجعة دمج، مع توافق العدادين وعدم تداخل الشريط والتنقل |
| بناء التطبيق | آخر بناء `pnpm build` ناجح بعد إصلاحات الواجهة؛ لا تغييرات تطبيق بعده |
| تشغيل jobs محليًا | `pnpm jobs:once` نجح؛ لا مشغّل دوري دائم أثناء الاختبارات |

إصلاحات المراجعة تشمل تسوية الإيقاف المتأخر بعد سقف Open، حماية الفترة الأحدث، العلاقات المركبة بين مالك السجل والفترة، إيقافًا محليًا بعد انتهاء lease، إعادة محاولة التجديد المؤقت الفشل، نهاية الجلسة أثناء وجود مسودة في صفحة أخرى، تفسير التوقيت المحلي عند قفزة DST، وتطابق شريط الجلسة مع تنقل التابلت. يبيّن تقرير المراجع دليل إعادة الفحص وحدوده.

الجولة الأخيرة أصلحت انتظار النشاط المرتبط قبل إتاحة Start، وثبّتت العرض المحلي عند وقت الإيقاف المنتظر دون تغيير سجل الخادم أو فترة أحدث. صُححت مقارنة timestamp في الاختبار لتقارن اللحظة الزمنية، وثُبتت ساعة Playwright قبل إنشاء مؤقتات الصفحة؛ الصور الناتجة عن تغيير أصل الساعة وسط الجلسة ليست دليلًا صالحًا. حُفظت تقارير الفشل، وتحقق عامل الدمج من hashes التقارير ومن نتيجة النجاح لكل رحلة في الفهرس.

## التخزين والتشغيل

طُبقت `20261101010000_time_ledger` ثم `20261101013000_time_compact_snapshots` بمعاملات، دون reset، مع نسخة DB خاصة قبل B4. المحاولة الأولى لإنشاء الامتداد تراجعت بالكامل بسبب غياب schema محلي، ثم نجحت بعد تعريفه؛ لا هجرة نصف مطبقة.

مفتاح dispatcher محفوظ خارج Git والمتصفح وعلى نظام ملفات يدعم صلاحيات 0600. أدوات الإعداد والإيقاف تتحقق من ملكية runtime، والإيقاف يتحقق أيضًا من ملف Compose الخاص بالحاويات. مطابقة PID تتحقق من ملف Node الفعلي، بما فيه الاستدعاء بمسار نسبي؛ لا توقف عملية لمجرد تشابه اسمها.

## الأداء وحدود الأدلة

على نفس شكل البيانات، 31 جلسة بفترة واحدة لكل جلسة، انخفض رد Renew من 28,904 إلى 1,850 بايت خام، بنسبة 93.6٪؛ القراءة المقتضبة 2,533 بايت. التاريخ الكامل يبقى بطلب صريح. [قبل](B4_TIME_PAYLOAD_PROBE.json) و[بعد](B4_TIME_PAYLOAD_PROBE_AFTER.json).

هذه نتيجة للسيناريو المقاس، وليست حدًا أقصى للرد أو تقديرًا مضمونًا لفاتورة الإنتاج. فترات الجلسة الواحدة ما زالت تُعرض كلها. يشمل B7 جلسة ذات 100 فترة وتاريخًا متراكمًا وحمل 50–100 مستخدم، وجدولة مستضافة وقياس التراكم والموارد.

إضافة Focus زادت حزمة مسارات العميل؛ [قياس الحزم](B4_BUNDLE_RESULTS.json) يذكر الأرقام وحدودها ولا يقدمها كتحسن. فصل تحميل المسارات وقياس الصفحات الكاملة ضمن مراجعة B7. الحزم المقاسة تستثني framework المشترك وCSS والخطوط وضغط النقل.

[فحص التسليم](B4_DELIVERY_CHECK.json) يتحقق من القيم السرية المعروفة والأصول الأصلية والروابط والصلاحيات؛ ليس بديلًا عن مراجعة أمن كاملة. لا تثبت هذه النتائج تشغيل Cloudflare/Supabase المستضافين، أو جدولة الإنتاج، أو قبول مستخدمين بشريين.
