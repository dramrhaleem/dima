# B2 — أول رحلة تعلم كاملة وتحسين الدارك

> سجل تاريخي لتسليم B2. قرار المستخدم اللاحق أوقف الدارك وطلب إصلاح التنقل؛ [التنفيذ الأحدث](UX_CONTINUITY.md) يتقدم على سياسة المظهر هنا.

31 أكتوبر 2026. البيئة: محلية حقيقية، Next/OpenNext على محاكاة Workers، وAuth + PostgreSQL + PostgREST. لا نشر على dima.study أو خدمات مدفوعة أو APK ضمن هذا التسليم.

## المنفّذ

- الدارك: خلفية فحمية، أسطح وحقول منفصلة، أزرار cobalt ونصوص مناسبة للتباين، وشعار معكوس بلا خلفية بيضاء. لا وميض إلى الثيم الفاتح عند إعادة التحقق من الجلسة في الخلفية. [فحص الدارك](DARK_REFINEMENT.json).
- مكتبة عامة قابلة للبحث والعودة إلى العرض المختار بعد الدخول، وفهرس يحافظ على Program/Course/Module/Task. [تدقيق المصدرين](../research/B2_COURSE_AUDIT_AR.md): 711 نشاطًا، مع توضيح اختيارية الدورة السابعة من Google ونسخة Harvard ذات تسعة أسابيع وحدود ترتيب Coursera العام.
- إنشاء/تعديل مسودة كورس خاص، ثم تثبيت نسخة الانضمام والنطاق والإنجاز السابق والتقديرات. التعديل اللاحق للمسودة لا يمس النسخة المنضم إليها.
- سعة أسبوعية واحدة لجميع الكورسات واحتياطي 15%، معاينة ثم تطبيق صريح. هدف مقابل توقع، متطلبات سابقة، كتل ≤45 دقيقة، تقديرات مؤقتة/مفقودة، وأعمال غير موزعة لا تختفي.
- Today وMy Courses وCourse وMy Plan تقرأ الحالة نفسها. فتح المصدر، Complete/Undo وتأكيد الجهد، وإعادة فتح/جهاز ثانٍ. السابق لا يولد ساعات أو إنجاز الأسبوع؛ الإعادة لا تكرر الحدث.
- صلاحيات خاصة وحماية التزامن والحسابات والحفظ الفاشل. [تفاصيل API والحفظ](../B2_API_AND_LEARNING_AR.md)، [خريطة الشاشات](../surfaces/b2-learning.md).

## أدلة التحقق

| الفحص | النتيجة |
|---|---|
| TypeScript + ESLint | نجحا على المصدر الحالي |
| اختبارات الوحدة | 36 نجحت؛ منها 15 للمجال والتخطيط |
| تكامل B2 الحقيقي | 18 فحصًا نجحت مرتين بحسابات اختبار مستقلة؛ [النتيجة](B2_LEARNING_API_RESULTS.json) |
| رجوع B1 | قاعدة البيانات 15، API الحساب 14، Auth 13؛ Google مفعّل محليًا. تسجيل Google التفاعلي كان قد تحقق في B1 ولم يُعاد في B2 |
| رجوع B0 | 12 تحقق backend و12 API نجحت |
| بناء عميل Vite المستقل | نجح؛ تحذير حجم chunk قرابة 536KB خام / 153KB gzip، وليس APK أو تحقق M0 |
| بناء Workers | نجح؛ مرآة البناء تطابق مدخلات المصدر |
| رحلات المتصفح | 8 رحلات نجحت: B2 أربع + B1/B0 أربع. أُعيدت الرحلتان المتأثرتان بتحسين الجدول والسابق على البناء النهائي ونجحتا؛ [سجل المتصفح](B2_BROWSER_RESULTS.json) |
| 21st review | أربعة ملفات واجهة: صفر ملاحظات؛ قيم palette نفسها تعريفات tokens، وليست أخطاء ألوان داخل المكونات |

المراجعة المستقلة راجعت المصدر والصلاحيات والجدولة وسبع صور. أصلحت ملاحظات جاهزية المتطلبات، فهرس الإنجاز، الخطة الخالية من العمل، الهدف الفائت، إعادة الطلب والترقيم. صور Library وToday وScope وPreview حدّثت بعد تصحيح الحالات؛ معاينة Harvard النهائية تختبر عرض أول 7 أيام ثم كل الأيام ثم الطي. المراجعة المستقلة الأخيرة لم تجد مشكلة مادية في طي الجدول أو الإنجاز السابق الجماعي. اختبارات المتصفح تستخدم بيانات اصطناعية، وليست تقدم صاحب المشروع.

## الحدود

- التشغيل محلي. Google ما زال Testing، والبريد لصندوق محلي. لا تحقق جديد لـCPU على Workers المستضاف أو حدود الخطة/الحمل/تجربة هاتف فعلي.
- ترتيب Google المتاح علنًا مجمّع حسب النوع، وليس إثباتًا لترتيب المشغل داخل الحساب. إنجاز ديمة يدوي، وليس تحققًا من المزود أو ضمان شهادة.
- الواجبات غير المقدرة في Harvard تبقى غير موزعة حتى يقدرها المستخدم؛ يمكن قبول الجزء الممكن بإقرار. لا اختلاق جهد دقيق.
- الصور والتحقق المتجاوب ليست شهادة وصول كاملة. الغرف والمؤقت والعمل الجزئي والاستدراك المتقدم والترتيب ليست ضمن B2.
- الأصول والوثائق الأصلية محفوظة، والسجل النهائي لفحص الأسرار والروابط في [فحص التسليم](B2_DELIVERY_CHECK.json).

الخطوة التالية في الخطة: M0، تجربة عميل Android/APK المحدودة قبل B3. لم تبدأ هنا.
