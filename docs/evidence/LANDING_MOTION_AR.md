## التنفيذ والتحقق

إعادة استخدام مكونات Dima الأصلية: Preview Switcher، Course Explorer وMagnetic Action. بحث21st راجع Scroll Reveal وغيره؛ لم ننسخ شيفرة جديدة أو نضيف مكتبة. تنفيذ مستقل باستخدام CSS وواجهات المتصفح. الزيادة المضغوطة للملفين نحو3.5KB؛ هذا قياس حجم ملفات، وليس اختبار Core Web Vitals أو قياس سرعة على جهاز ضعيف.

البناء وفحص TypeScript وLint للنطاق المعدل نجحوا. رحلة متصفح مركزة نجحت: تبويبات بالكيبورد، تقدم النموذج التجريبي، أيام الخطة، معاينة التعافي، روابط الكورسات، عدم وجود تمرير أفقي عند1440/390/320px، واحترام reduced motion. لا أخطاء JavaScript في الرحلة. مراجعة21st:0 أخطاء،0 تحذيرات،12 اقتراح ألوان معلوماتي ضمن ألوان الهوية الثابتة.

المراجعة البصرية تمت للكمبيوتر والموبايل، ثم تأكدت النسخة المنشورة في Chrome والتفاعل مع Plan. لم نعد اختبارات الباك اند غير المتأثر. لا تعديل بيانات حسابات أو قاعدة البيانات.
