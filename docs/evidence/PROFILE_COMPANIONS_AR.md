# البروفايل ورفقاء الكورس وحركة الترتيب

## التغيير
- الاسم والصورة في الشريط الجانبي وأعلى الصفحة يفتحان إعدادات البروفايل. يمكن تعديل الاسم ورفع صورة أو إزالتها أو العودة إلى صورة Google.
- صورة Google تأتي من بيانات تسجيل الدخول الموجودة، دون صلاحيات Gmail. اختيار صورة خاصة أو إزالتها لا يُستبدل تلقائيًا في تسجيل الدخول التالي.
- الصور المرفوعة تتحول إلى مصغّر مربع 256 بكسل. الخادم يتحقق من النوع والحجم والأبعاد؛ الإعادة بنفس العملية آمنة، وتعارض التعديل قابل للمراجعة. لا صور مضمنة في ردود متابعة الكورس.
- الترتيب يتحدث كل20 ثانية عند ظهور الصفحة، مع صور الأعضاء وانتقال المراكز وإشارة الزيادة وفرقعة صغيرة عند زيادة جديدة. لا احتفال عند الفتح الأول أو إعادة الاتصال أو التصحيح للخلف.
- صفحة محتوى الكورس تعرض تقدم الرفقاء وآخر نشاط مطلوب مكتمل، وأسماءهم وصورهم بجانب الموديول والنشاط المطابق. الرابط يفتح الموديول مباشرة. التقدم الجديد يحرك الصورة مع قفزة وفرقعة قصيرة.
- الإظهار التفصيلي للموقع داخل الكورس اختيار منفصل لكل إصدار منشور، مع احترام إخفاء الترتيب والحظر المتبادل. لا تُنشر مواقع الكورسات الخاصة. لا تغيير في خيارات المالك أو إنجازاته لغرض التجربة.

## حدود واضحة
- متابعة مواقع الكورس تحديث تلقائي كل15 ثانية أثناء ظهور الصفحة، وليست WebSocket فورية. عند انقطاع الاتصال تُزال البيانات المعروضة ويُعاد الاتصال بتدرج؛ لا يُفترض أن الشخص متصل الآن.
- الموقع هو آخر إنجاز محفوظ، وليس الشاشة التي يفتحها العضو أو دليل أنه يذاكر الآن. الإنجاز السابق والتراجع لا يطلقان احتفال تقدم جديد.
- المقارنة داخل نفس الإصدار المنشور وبمتطلبات الكورس الكاملة. العرض حتى100 مشارك مع إظهار حد العرض، ويُدرج المستخدم نفسه إن كان يشارك.
- الحركة تحترم تقليل الحركة، ولا صوت تلقائي جديد. الصور عبر endpoint يتطلب تسجيل الدخول ويراعي الحظر قبل إعادة304.
- مشكلة Cloudflare CPU / Error1102 السابقة مستقلة وغير محلولة بهذا التغيير؛ لا ترقية مدفوعة أُجريت.

## التحقق
نجح فحص الأنواع والـlint والبناء، و10 اختبارات وحدة و4 مجموعات API محلية و5 رحلات متصفح على البناء النهائي. روجعت الإعدادات والرفقاء والترتيب عند1280 و390 بكسل؛ أُصلح التمدد الأفقي لمؤشر التقدم وثبت عدم تجاوزه العرض.

طُبق ترحيلا56000 و57000، ونُشر الإصدار `f5580d29-a4cd-40ac-88d6-bca3e4d1813c`. تطابق BUILD_ID الحي، ونجح Health200 وحماية Me والصورة401. تأكد ظهور صورة Google الفعلية في حساب المالك، وأزرار البروفايل، ومتابعة الكورس15 ثانية والترتيب20 ثانية، مع بقاء الإخفاء السابق وإنجازات المالك دون تغيير. رُفضت أول محاولة نشر برمز10000؛ بعد تحديث جلسة OAuth الحالية نجحت إعادة واحدة.

حركة التقدم والترتيب اختُبرت بلقطات ردود مضبوطة محليًا، بينما حفظ الإنجاز وإرجاع الموقع والحظر والانسحاب اختُبرت على قاعدة البيانات والـAPI المحليين. لا ادعاء بتجربة تقدم عدة مستخدمين حقيقيين في الإنتاج. [التفاصيل الآلية](PROFILE_COMPANIONS_VERIFICATION.json).
