## الرصد قبل الإصلاح

- فتح Leaderboard من كورس قد يعرض الترتيب العام وزر الاشتراك فيه قبل حل نطاق الكورس، أو يبقيه عند غياب نطاق مقارن.
- الملف المشترك يعرض Request to follow حتى مع وجود طلب أو علاقة؛ الرابط المنسوخ مع query أو fragment يرسل قيمة خاطئة.
- Refresh settings بعد تعارض تحرير البايو العام يعيد تركيب النموذج ويزيل المسودة.

## الإصلاح

- فصل اكتشاف نطاق الكورس عن عرض الترتيب. لا يظهر الاشتراك العام عند انتظار نطاق كورس أو غيابه؛ هناك رابط صريح للترتيب العام.
- الطلب المعلق/المتابعة/الطلب الوارد يظهر بإجراء مناسب يقود لإدارته في People، ومنع الإرسال حتى معرفة الحالة.
- استخراج اسم المستخدم من رابط Dima الصحيح مع تجاهل query وfragment، ورفض الروابط الخارجية أو صفحات غير الملفات.
- تحديث الملف العام يحفظ المسودة عند تعارض النسخ. يعرض النسخة المحفوظة ويعطل الحفظ إلى أن يختار المستخدم استخدامها أو الاحتفاظ بمسودته، ثم حفظ صريح مستقل.

- اختبارات API محلية للمشاركة والمتابعة والحظر والنشر والاحتساب: 7 حالات نجحت قبل الدمج؛ لا تغيير لقواعد الخادم في هذه الدفعة.
