# B1 — الحسابات والصلاحيات وتجربة الدخول

31 أكتوبر 2026. **B1 مبني ويعمل محليًا على Workers.** تحقق Google الفعلي ونتيجة تسليم المرحلة مذكوران أدناه؛ لا نشر على dima.study أو إثبات CPU مستضاف أو APK.

## ما نُفّذ

- دخول Email OTP حقيقي عبر Supabase Auth وSMTP إلى Mailpit محلي؛ رفض الكود غير الصحيح أو المستعمل، جلسة HttpOnly، وتجديد فعلي بعد انتهاء access token. لا كلمات مرور أو tokens في واجهة B1 أو localStorage.
- Google OAuth عبر PKCE وعميل مخصص لديمة؛ عناوين العودة محصورة، أخطاء وإلغاء آمنان، والصلاحيات email/profile فقط.
- ملف خاص: الاسم، timezone، نية التعلم/العمل، المظهر والحركة؛ onboarding قابل للاستئناف. اختيار العمل لا يتطلب كورسًا.
- RLS وrole منفصل عن metadata المستخدم، فصل الملف العام الخاص بالعرض عن الإعدادات الخاصة، لا نشر تلقائي. حفظ ذري بـoperationId وrevision، وحماية تغير الحساب قبل الطلب وبعد وصول الرد.
- Auth، Onboarding، Today، Settings، shell للكمبيوتر والهاتف، loading/error/empty/conflict، تبديل الحساب، قفل العرض الخاص فور فشل الخروج مع إعادة المحاولة. الصفحات القادمة واضحة كغير متاحة، دون وقت أو تقدم وهمي.
- اللاندنج المقبولة تعمل على `/` وروابطها تدخل الحساب والمكتبة. الشعار والأصول المرجعية محفوظة دون تغيير؛ `/dev/foundation` يحتفظ بفحص B0.

## إعداد Google الفعلي وحدوده

بعد تفويض المستخدم ثم تأكيده المحدد لقبول Google API Services: User Data Policy وإنشاء OAuth:

- الحساب بلغ حد إنشاء المشاريع؛ استُخدم مشروع قائم بلا مفاتيح API أو عملاء OAuth أو حسابات خدمة ظاهرة وقت الفحص. لم يُحذف مشروع أو يُعدّل تطبيق آخر.
- أُنشئ branding باسم Dima — ديمة وعميل Dima Local Web — B1، في وضع Testing، وأضيف حساب المستخدم إلى قائمة الاختبار.
- Google callback المصرح هو localhost الخاص بـAuth؛ لا عنوان إنتاج لم تُثبت خدمته.
- سر Google محفوظ في ملف 0600 خارج المشروع، ولا ينسخ إلى web bundle أو mirror. يقرأه Auth المحلي فقط. لا حفظ في localStorage أو مستودع.
- إثبات العودة إلى ديمة وإنشاء الملف وإعادة فتحه محفوظ في [دليل Google](B1_GOOGLE_RESULTS.json). هذا لا يثبت إتاحة تسجيل الدخول للجمهور أو تفعيل Supabase/Cloudflare مستضافين.

## حدود المنتج والتشغيل

- SMTP محلي ملتقط؛ لا بريد عام أو مزود إرسال إنتاجي. Google يعمل فقط ضمن إعداد الاختبار المصرح به؛ لا publish للتطبيق.
- Library والصفحات المستقبلية مواضع واضحة للمراحل التالية؛ لا بدء جلسة أو تسجيل تقدم أو غرف/ترتيب/متابعة. AC02 كامل في B4، وروم AC01 كامل في B5.
- privacy/terms صفحات تنبيه للمعاينة وليستا سياسات تشغيل قانونية نهائية؛ مطلوب إكمالها قبل إطلاق عام.
- لا تصدير/حذف حساب/تنبيهات/طابور إنجاز غير مبني. لا ادعاء اختبارها ضمن AC03/AC04.
- Auth وDB على الجهاز؛ DNS والنشر وCPU البعيد والحمل والاستعادة وAndroid باقية في بواباتها. لا ضمان سعة إنتاج أو مجانية دائمة من هذه النتائج.
- مراقبة الأخطاء هنا ردود آمنة وrequestId لأوامر الملف واختبارات تمنع تسريب البيانات؛ تنبيهات التشغيل وتجميع أخطاء الإنتاج ليست موصولة بعد.
