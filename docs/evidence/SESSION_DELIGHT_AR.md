# الفافيكون وتجربة الجلسات والتنبيهات

## المنفذ

- ربط الفافيكون الأصلية بكل الصفحات بما فيها اللاندنج، مع SVG وPNG وICO متعدد الأحجام وأيقونة Apple. الأصل المعتمد محفوظ؛ ملفات PNG مغلفة دون إعادة رسم. روابط ذات إصدار لتجاوز ذاكرة الأيقونة القديمة.
- بدء الدورة المشتركة لم يعد يحتاج هوست: أي عضو ذو مقعد ساري وتحكم صحيح يستطيع بدء دورة جاهزة. بدء متزامن من عضوين ينتج دورة واحدة. لا تغيير ضمني للمشرف أو المالك، ولا بدء تلقائي للوقت الشخصي.
- دور الإشراف منفصل في الواجهة عن ساعة الدراسة. استعادة الدور ضمن تفاصيل ثانوية، وأدوات نقل الدور والإزالة محفوظة.
- مؤشر للجولات الأربع يوضح الجولة الحالية والراحة والجولات المنتهية. هذا تقدم الدورة المشتركة، لا شهادة على وقت أو إنجاز شخص بعينه.
- نغمة قصيرة اختيارية عند اكتمال جولة فردية طبيعيًا، وانتهاء استراحة جرى تتبعها، وانتقال مرحلة غرفة مؤكدة. توجد تجربة للصوت وكتم، مع تفضيل محفوظ لكل حساب في المتصفح. لا صوت افتراضي مفاجئ أو تشغيل لجلسة جديدة.

## التحقق

نجح30 اختبار وحدة، و3 مجموعات API فعلية محلية، و9 رحلات متصفح مختلفة متعلقة بالتغيير، وفحص الأنواع والـlint والبناء والتجهيز للنشر. شملت الرحلات عضوًا يبدأ دورة بعد خروج المالك دون اكتساب إشراف، انتقال الراحة والجولة التالية دون تشغيل وقت شخصي، التنقل وأزرار التحكم على الشاشات الضيقة، والتشغيل الفعلي لعقد Web Audio بعد ضغطة التفعيل وعند الانتقالات والكتم.

هذه أدلة تشغيل برمجي للصوت، وليست ادعاء استماع بشري لمستوى الصوت على كل جهاز. التبويب النائم أو المغلق قد يفوت التنبيه؛ التفعيل قد يلزم مجددًا بعد فتح الصفحة. منع التكرار بين التبويبات يستخدم Web Locks والتخزين حيث يتاحان، ويصبح أفضل جهد عند غيابهما. لا اختبار حمل جديد أو ادعاء سعة إنتاجية جديدة.

## الشات: مقترح وليس ميزة منشورة

يمكن تنفيذه على البنية الحالية دون اختيار خدمة شات إضافية. الترشيح شات نصي جانبي، مطوي وصامت أثناء التركيز، والإرسال في الانتظار والاستراحة، مع إبلاغ وحظر وحذف وحد للإرسال. تفاصيل الصلاحيات وإعادة المحاولة والحذف والاحتفاظ والحدود في [تصميم الغرف والشات](../ROOMS_EVOLUTION_PROPOSAL_AR.md). لم تُنشأ جداول شات أو صلاحيات رسائل أو سياسة احتفاظ فعلية ضمن هذا الإصدار.
