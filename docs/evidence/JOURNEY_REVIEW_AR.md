# مراجعة رحلة ديمة صفحة بصفحة — 1 نوفمبر 2026

النطاق: نسخة الويب، ترتيب الإجراءات وربط الصفحات وصحة السلوك، مع استجابات حركية قصيرة. الحفاظ على الوظائف والهوية والوضع الفاتح؛ لا تطبيق هاتف أو خدمات مدفوعة جديدة. المراجعة مصدرية ووظيفية وليست دراسة استخدام على جمهور حقيقي أو ضمانًا بخلو كل سيناريو من عيوب.

## خريطة المراجعة

| الصفحة أو المسار | هدف المستخدم والإجراء الأساسي | معيار التحقق |
|---|---|---|
| Landing / Library العامة | فهم المنتج واختيار البداية | الروابط والمعاينة وتقليل الحركة؛ دليل إصدار اللاندنج السابق يعاد استخدامه |
| Auth / Onboarding | الدخول والوصول للوجهة المطلوبة | رمز بريد حقيقي محلي، حفظ البداية والوجهة |
| Today | معرفة الخطوة التالية | نشاط قابل للتنفيذ أو بدء عمل دون كورس |
| My Courses / تفاصيل الكورس | متابعة المحتوى مع حفظ الإنجاز | الإكمال والجزئي والتراجع وترقية المنهج |
| Library / إضافة الكورس | اختيار كورس ونطاق وهدف | حفظ الاختيارات دون تكرار أو فقد تقدم سابق |
| الكورس الخاص / Contributions | بناء منهج ومشاركته | حفظ مسودة، إرسال snapshot فقط للمراجعة |
| My Plan / Recovery | خطة قابلة للتطبيق والرجوع بعد التعثر | معاينة قبل التطبيق، عدم مسح التاريخ، تعارض النسخة |
| Solo Focus | جلسة وقت صحيحة | بدء وتوقف وإنهاء، ربط اختياري بالدرس |
| Study Rooms | اختيار غرفة ثم المشاركة بإرادة المستخدم | الدخول منفصل عن التايمر، تبديل الغرفة أو الوضع بأمان |
| Progress / Activity | فهم الإنجاز والوقت | معنيان منفصلان، إجراءات تصحيح الوقت واضحة |
| Community / Sharing | اتصالات ومشاركة اختيارية | أذونات مستقلة، متابعة بموافقة، حظر ورابط عام |
| Leaderboards / Milestones | منافسة وتشجيع بمقاييس صحيحة | الاشتراك اختياري وعدم تكرار أرصدة الإنجاز |
| Notifications | معرفة ما يحتاج إجراء | قراءة الرسالة والوصول للسياق |
| Administration | مراجعة نشر وإدارة البلاغات | صلاحية الخادم، سبب القرار، احتفاظ المتعلمين بمنهجهم |
| Settings / Account data | حفظ تفضيلات وإدارة الحساب | حفظ تغييرات فعلية، تعارض الأجهزة، تصدير وحذف مثبت |
| Help / More / وجهة خاطئة | الوصول للخطوة الصحيحة | روابط مفيدة وحالة خطأ صريحة بدل وعود قديمة |

## قواعد الحركة

- انتقال محتوى قصير عند تغيير القسم دون إعادة تركيب الـworkspace أو المؤقتات.
- استجابة للحفظ والنقر وتغير حالة الميزة؛ لا حركات متكررة حول العدّاد.
- احترام تفضيل الحساب والنظام لتقليل الحركة، وإيقاف الانتقال عند إخفاء الصفحة.
- لا تأخير لتمكين زر أو حفظ عملية من أجل الأنيميشن.

## التحقق

- فحص TypeScript وESLint نجح؛ 205 اختبارات وحدة في 24 ملفًا نجحت.
- 13 حالة API محلية نجحت: 7 للمجتمع والنشر والصلاحيات، و6 لتصدير الحساب وحذفه؛ حسابات اصطناعية فقط.
- 21 رحلة متصفح محددة نجحت: 18 في الجولة المجمعة، و3 في إعادة فحص بعد تصحيح محددات الاختبار وتوقيته. شملت الإضافات الجديدة للحفظ/التراجع/تركيز الأخطاء، اكتشاف نطاق الترتيب، تعارض البايو، إعادة تحميل الأنشطة، الاستراحة، وروابط الجدول والتعافي.
- اختبار الحركة أثبت تشغيل انتقال المحتوى في الوضع العادي وعدم تشغيله مع تفضيل النظام لتقليل الحركة. اختبارات التنقل والخلفية أثبتت بقاء الـworkspace ومسودة الإعدادات والجلسة.
- مراجعة مرئية للقطات جديدة: Today، الكورس، التعافي، النشاط، التركيز، ملخص الجلسة، Progress والإعدادات، بعروض كبيرة وضيقة. فحص overflow ضمن الرحلات. صفحة الغرفة تعرض إجراءات الجلسة فوق شريط التنقل عند 320 و375 و768px، وتعرض شريط الجلسة عندما يغادر المستخدم صفحة تحكمها.
- بناء الإنتاج وdry-run نجحا وبصمة المصدر مطابقة. لا تغيير قاعدة بيانات في هذه الدفعة.

الأدلة المحلية: `.local/journey-check.log`، `.local/journey-browser.log`، `.local/journey-browser-recheck.log`، `.local/journey-community-core.log`، `.local/journey-account-core.log`. اللقطات في `.impeccable/review/`؛ لوحة المراجعة `journey-contact-sheet.png`.

## حدود النتيجة

هذه جولة تحسين وتحقق للمسارات الأساسية والحالات المعدلة، وليست إثباتًا أن كل سيناريو ممكن خالٍ من العيوب. لم نكرر الحمل المطول أو كل سباقات التزامن السابقة. لا اختبار iOS/Android على جهاز فعلي، ولا تطبيق هاتف. تعديل outline أو نموذج لم يُحفظ قبل مغادرة صفحته ليس له autosave عام بعد؛ لا نَعِد باستعادة تلك المسودات. مسودة الملف العام في تعارض النسخ والإعدادات أثناء background refresh تم اختبار حمايتهما تحديدًا.
