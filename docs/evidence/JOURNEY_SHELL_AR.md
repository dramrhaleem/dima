# رصد رحلة الحساب والتنقل — قبل الإصلاح

1. إعدادات الحساب تعرض Save changes حتى دون تغيير، ولا توفر رجوعًا واضحًا عن التعديلات قبل الحفظ؛ كل ضغطة تنشئ مراجعة حفظ بلا فائدة.
2. أخطاء النموذج المخصصة لا تنقل التركيز لأول حقل خاطئ، والانتقال إلى خطوة رمز البريد لا يركز حقل الرمز.
3. رسائل فشل تنزيل الحساب تستخدم افتراضيًا صياغة تخص حذف الحساب؛ لا تطابق العملية التي أجراها المستخدم.
4. طلب حذف فشل في مرحلة التنظيف يعرض Request new code رغم أن المطلوب إكمال الطلب الموجود؛ وإغلاق التفاصيل يسمى Cancel بما قد يوحي بإلغاء الحذف.
5. الوجهات غير المعروفة تعرض رسالة قديمة عن ميزات مستقبلية بدل توضيح عدم وجود الصفحة. صفحة المساعدة نفسها موجودة ومفيدة.
6. التنقل يحتفظ بالـworkspace لكنه لا يقدم انتقالًا بصريًا خفيفًا يوضح وصول محتوى جديد. نضيف انتقال محتوى فقط دون إعادة تركيب البيانات أو المؤقت.

هذه ملاحظات من مراجعة المصدر؛ دليل التنفيذ والاختبارات سيضاف بعد دمج المسارات.

## ما تغير

- حفظ الملف يتطلب تعديلًا فعلًا؛ Discard changes يعيد آخر نسخة حفظها النموذج، ورسالة تميز غير المحفوظ. لا ندّعي حفظ مسودات تلقائيًا عند مغادرة الصفحة.
- تركيز حقل رمز البريد بعد طلبه، وأول حقل غير صالح عند الإرسال. توضيح عدم توفر وسيلة الدخول بدل زر معطل بلا سبب.
- تصدير الحساب له رسالة خطأ تخص التنزيل، ورسالة نجاح تصف طلب التنزيل دون الادعاء أن المتصفح حفظ الملف.
- فشل تنظيف الحذف يتيح استكمال الطلب الموجود؛ إخفاء التفاصيل لا يسمى إلغاءً، ولا يعرض إنشاء رمز جديد.
- روابط المساهمة والإدارة نُقلت إلى مجموعة ثانوية بجانب الحساب والمساعدة، مع رموز مناسبة بدل سهم عام لكل شيء.
- الوجهة غير المعروفة لها رسالة واضحة وطريق إلى Today أو Help؛ أزيلت أوصاف الميزات المستقبلية القديمة.
- انتقال محتوى180ms دون إعادة تركيب الـworkspace أو تعطيل الأزرار؛ استجابة قصيرة للحفظ وفتح التفاصيل. احترام تقليل الحركة وإخفاء الصفحة.
- حقول الدخول والملف على العرض الصغير16px لتجنب التكبير التلقائي المعتاد في iOS؛ لم نختبر جهاز iOS فعليًا.

## أدلة النطاق

ESLint وفحص TypeScript نجحا للنطاق الأولي. اختبار المتصفح الجديد يغطي الحفظ/التراجع/تركيز الخطأ ورسالة فشل التنزيل وحالة تنظيف حذف فاشلة محاكاةً، دون حذف الحساب في المتصفح. اختبار API المحلي المنفصل أثبت6 حالات للحذف والتصدير على حسابات اصطناعية؛ ليس حساب المالك. نتائج الدمج النهائية تسجل في التقرير الرئيسي.
