## ما يعمل الآن

اللاندنج على `/`، التسجيل على `/auth`، الإعداد الأول على `/onboarding`. داخل `/app`: اليوم، الكورسات والمكتبة، الخطة والاستدراك، التركيز الفردي والغرف، التقدم والمعالم والمتابعة والترتيب والمساهمات والإعدادات والإدارة. الملف العام اختياري على `/u/handle`؛ تحديثات المنهج بمعاينة وموافقة وحفظ السجل القديم. فحص B0 للتطوير محجوب في الإنتاج.

الأوامر الأساسية: `pnpm check`، `pnpm build`، `pnpm build:client`؛ إعداد قاعدة البيانات والبيئة واختبارات المتصفح مفصلة في دليل التشغيل. ملفات البيئة الحقيقية خارج Git، ولا توجد مفاتيح مشروع آخر أو نشر تلقائي.

## حدود الجاهزية

Cloudflare Workers + Supabase Free، والدومين لدى Spaceship وDNS/HTTPS على Cloudflare. دخول Google والبريد والجدولة والغرف المستضافة تحققت مباشرة. `support@dima.study` تحويل وارد مُختبر؛ إرسال الردود باسمه غير مُعد. لا اشتراك مدفوع جديد. CI لم يُشغّل على مستودع GitHub بعيد، ولم يُجرَ اختبار حمل مطول أو إصدار Android. [دليل النشر](docs/WEB_DEPLOYMENT_RUNBOOK_AR.md).

الوثائق الحالية مرجع التنفيذ هنا. وثائق v1.1 الأصلية في مجلد Kanaf محفوظة دون تغيير، وبصماتها في `docs/SOURCE_MANIFEST.json`. حزمة ZIP v1.2 الموجودة في artifacts لقطة تخطيط سابقة وليست تسليم الكود الحالي. الأصول المرجعية نُسخت مع سجل مصدر وحقوق؛ لا بيانات كنف التشغيلية.
